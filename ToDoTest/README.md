# To-Do List Web App

## Description
A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.
Users can:
- Add tasks
- Delete tasks
- Clear all tasks
- Tasks are saved in Local Storage to persist after page refresh

## Features
- Responsive design
- Hover effect on tasks
- Alternating row colors for readability
- Clear All button for convenience

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
